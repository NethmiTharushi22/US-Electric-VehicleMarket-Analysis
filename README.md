# 🔌 US Electric Vehicle Market Analysis

Analyzed EV adoption across U.S. states to identify infrastructure investment opportunities using SQL and Power BI.

---

## 📊 What I Did

**Data & Analysis**
- Cleaned & validated vehicle registration data in PostgreSQL
- Calculated EV, PHEV, HEV market share by state
- Identified top EV adoption states (CA, DC, HI)
- Compared California vs. Texas, Florida, New York

**Dashboard Development**
- Built interactive Power BI dashboard with KPIs
- Created state-level EV adoption map
- Designed fuel type distribution analysis
- Implemented drill-down filters for state-specific insights

---

## 🛠️ Tech Stack

**PostgreSQL 15** | **SQL** | **Power BI** | **pgAdmin 4** | **Excel**

---

## 🎯 Key Findings

- California leads in EV adoption nationally
- Gasoline still dominates but EV market growing rapidly
- Infrastructure availability directly correlates with adoption rates
- Clear opportunity for targeted investment in low-adoption states
